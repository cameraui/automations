# camera.ui - Automations

Shareable automation blueprints for the camera.ui ecosystem.

camera.ui reads this repository for the community store on the Automations page. To share a blueprint, export it in camera.ui with **Export blueprint** and open a pull request that adds the file to [`blueprints/`](./blueprints). See [Blueprints](https://docs.cameraui.com/automations/blueprints#community-blueprints) in the docs.

_Part of camera.ui, the local-first camera and NVR platform._
